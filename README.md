# Personal Platform

Реальная web-платформа для автоматизации личных рабочих процессов: работа с файлами (PDF/DOCX/XLSX), задачи и инструкции, AI-обработка данных.

**Статус:** Phase 0 — infrastructure bootstrap (Git + Debian + SSH + Docker → первый deployment).

## Цели проекта

- production-like backend-система (modular monolith) на собственном Debian-сервере;
- учебная среда backend-инжиниринга и портфолио.

## Репозиторий

- `origin` — GitHub (основной remote);
- `gitlab` — GitLab (зеркало).

Публичная документация будет дополняться по мере развития фаз проекта.
